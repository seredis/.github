https://github.com/seredis/ is the home of SE.Redis - i.e. StackExchange.Redis

The StackExchange.Redis library was originally created and maintained by Stack Exchange Inc. and made available to the public via the MIT license.

More recently, it is primarily maintained by Marc Gravell (ex-"Stack", now working at Redis Ltd.), Nick Craver (ex-"Stack", now working at Microsoft Corporation), and Philo Nordland (Microsoft Corporation).

While Redis and Microsoft are forefront in terms of maintenance, the library does not prejudice against other implementations - it aims to work well against any RESP server implementation.

We remain grateful to Stack Exchange for starting this work and making it available to the .NET community.
